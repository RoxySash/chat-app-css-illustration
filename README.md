### What I learned

Something as simple as a vertical ellipsis sent me down a rabbit hole, which led me to discover HTML entities and unicode characters.

To see how you can add code snippets, see below:

```html
<p>Vertical Ellipsis: &vellip;</p>
<p>Less-Than Sign: &lang;</p>
<p>Greater-Than Sign: &gt;</p>
```
```css
.chat-exit {
  font-size: 1.12rem;
  font-weight: 600;
  color: var(--white);
}

.chat-options {
  font-size: 1.12rem;
  font-weight: 600;
  color: var(--white);
}
```
